# VORLDA

ورشة تركيب موحدة للتطبيقات والصور والفيديو والشخصيات، مع محفظة استخدام بالدولار وثلاث باقات اشتراك.

## ما يعمل في هذه النسخة

- ورشة مكانية: قطع متداخلة، طبقات، تحريك وتحجيم ودوران، تحديد متعدد، تجميع، قواعد مشتركة، تخصيص للجوال، نسخ مستقل/مرتبط/بديل، ونسخة عمل مرتبطة خارج المصدر.
- حفظ دائم للمشاريع والملفات، كشف تعارض المسودات، سجل نسخ، استعادة إلى المسودة، صلاحيات أعضاء وتعليقات.
- صفحات وأزرار وروابط ونماذج فعلية، معاينة، نشر خاص، وتصدير مشروع بملفاته أو HTML مستقل أو PNG أو فيديو متصفح مع الصوت.
- محفظة دولار دقيقة بوحدات صحيحة، رصيد اشتراك ورصيد إضافي، عرض تكلفة قبل الاعتماد، تطبيق وخصم ذريان، وسجل حركة ومنع تكرار الخصم والمنح.
- ثلاث باقات قابلة للتهيئة، وربط Stripe غير مفعّل. مبلغ 100 دولار للتجربة مثالٌ من طلب المالك، وليس سعر اشتراك معتمدًا.

## حدود الاكتمال

هذه نسخة عاملة للتحرير اليدوي والبنية والمحفظة، وليست تنفيذًا مكتملًا لكل محركات الرؤية الكانونية. التوليد الذكي، التفكيك الدلالي، إعادة بناء الأجسام، التتبع الذكي، المتحدث الرقمي، والتصدير السينمائي الطويل تحتاج تنفيذًا وتكاملات إضافية. لا يوجد خصم أو ادعاء نجاح لهذه القدرات غير المفعّلة.

الدفع الحقيقي غير مفعّل. اعتماد أسعار الباقات والاستخدام، وسياسة الرصيد، وربط حساب التاجر واختباره، وتسويات رد المدفوعات والاعتراضات تسبق التحصيل الحقيقي.
