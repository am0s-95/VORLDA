# VORLDA

ورشة تركيب موحدة للتطبيقات والصور والفيديو والشخصيات، مع محفظة استخدام بالدولار وثلاث باقات اشتراك.

## ما يعمل في هذه النسخة

- ورشة مكانية: قطع متداخلة، طبقات، تحريك وتحجيم ودوران، تحديد متعدد، تجميع، قواعد مشتركة، تخصيص للجوال، نسخ مستقل/مرتبط/بديل، ونسخة عمل مرتبطة خارج المصدر.
- حفظ دائم للمشاريع والملفات، كشف تعارض المسودات، سجل نسخ، استعادة إلى المسودة، صلاحيات أعضاء وتعليقات.
- صفحات وأزرار وروابط ونماذج فعلية، معاينة، نشر خاص، وتصدير مشروع بملفاته أو HTML مستقل أو PNG أو فيديو متصفح مع الصوت.
- محفظة دولار دقيقة بوحدات صحيحة، رصيد اشتراك ورصيد إضافي، عرض تكلفة قبل الاعتماد، تطبيق وخصم ذريان، وسجل حركة ومنع تكرار الخصم والمنح.
- ثلاث باقات بأسعار 29 / 79 / 199 دولار وأرصدة 30 / 90 / 250 دولار، وتجربة مزاياها دون دفع. التحصيل الحقيقي يبقى غير مفعّل حتى تهيئة التاجر واختباره.
- حدود مساحة وعمليات متزامنة ومقاعد فريق مفروضة على الخادم، مكتبة إعدادات إنتاج وهويات مشاريع، تصدير دفعات ZIP، مراجعات نشر مرتبطة بالنسخة، وحدود صرف للأعضاء.
- التحرير اليدوي مجاني. مسار توليد صورة عبر Replicate مكتوب مع حجز الرصيد ومنع إعادة الطلب، حفظ الأصل الخاص، واسترداد الرصيد عند الفشل. اختُبر بمزوّد بديل محلي فقط؛ لا يوجد مفتاح توليد حقيقي متصل.
- تصدير كود التطبيق الأصلي مع ملفات البناء وخادم Node/SQLite لردود النماذج، قابل للتشغيل خارج VORLDA. خيار لوحة إدارة لمالك التطبيق منفصل عن حسابات العملاء؛ الدفع والذكاء الاصطناعي غير مضمنين. [تفاصيل حزمة المصدر](docs/RELEASE-PORTABILITY.md) و[حساب الإدارة والاختبار المعزول](docs/OWNER-ADMIN-AND-TESTING-2026-09-05.md).

## حدود الاكتمال

هذه نسخة عاملة للتحرير اليدوي والبنية والمحفظة، وليست تنفيذًا مكتملًا لكل محركات الرؤية الكانونية. ربط التوليد الحقيقي، سلاسل العمل المجدولة، توليد الفيديو والصوت، التفكيك الدلالي، إعادة بناء الأجسام، التتبع الذكي، المتحدث الرقمي، والتصدير السينمائي الطويل تحتاج تنفيذًا وتكاملات إضافية. لا يوجد خصم أو ادعاء نجاح لهذه القدرات غير المفعّلة.

الدفع الحقيقي غير مفعّل. قياس أسعار الاستخدام واعتمادها، وتنفيذ سياسة انتهاء رصيد الاشتراك، وربط حساب التاجر واختباره، وتسويات رد المدفوعات والاعتراضات تسبق التحصيل الحقيقي.
