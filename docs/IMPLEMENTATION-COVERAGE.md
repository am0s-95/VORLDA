# مراجعة الأرشيف وتغطية التنفيذ

تمت مراجعة الإصدارات الستة 1.0–1.5 واستخراج Application World، ومطابقة أزواج Markdown/Word وحساب بصمات الملفات الأربعة عشر. فروق Word الكبيرة غلاف وبيانات وثيقة وفهارس؛ فروق أخرى ترقيم وعلامات تنسيق. سجل المطابقة في `archive-integrity.json`. جميع النسخ الأصلية محفوظة دون تعديل.

المرجع التشغيلي v1.5 ثم طلب المالك الأحدث: الدولار بدل الكريدت، ثلاث باقات فقط، ورصيد اشتراك مع شحن إضافي. لا نأخذ مجانية التحرير القديمة في v1.0/1.1 أو المجالات العامة القديمة لإلغاء تخصيص النسخ اللاحقة. الأرقام التجارية غير معتمدة.

**دلالة الحالات:** «منفذ» يعني نطاقًا محددًا موضحًا بالملاحظة؛ «جزئي» يعني وجود أساس عامل مع نواقص؛ «غير منفذ» قدرة حقيقية تحتاج عملًا إضافيًا أو مزوّدًا؛ «مرجع» تعريف أو سجل محفوظ. لا تمثل القائمة وعدًا بأن مجرد إدخال مفتاح API يكمل المحركات الناقصة.

## خلاصة الاختبار

اختبارات النواة والخادم والدفع الموقّع والمحاكاة المالية وعرض الصفحة على الخادم موجودة في `tests/`. لم تُجر اختبارات متصفح أو دفع تاجر حي. التصدير الفلمي يعتمد MediaRecorder، ولم يسجل ملف فيديو خلال هذه الجلسة.
