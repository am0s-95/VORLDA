# الأدوات حسب الحاجة

طلب المالك إظهار التفاصيل التقنية عندما يحتاجها المستخدم، بدل عرض كل شيء للجميع داخل الورشة.

- الوضع الافتراضي «تلقائي»: يظهر مدخل البرمجة عندما يحتوي المشروع على قطعة كود. المشاريع العادية لا تعرضه في الشريط أو قائمة القطع.
- تبقى قائمة «الأدوات حسب الحاجة» متاحة لفتح ملفات البرمجة واستيراد أول مصدر، حتى في مشروع لا يحتوي كودًا. البحث المقصود عن الكود أو البرمجة يظهر القطعة في قائمة الإضافة.
- يستطيع المستخدم اختيار «مبسط» أو «متقدم» أو العودة إلى «تلقائي». الاختيار تفضيل محلي على الجهاز ومفصول بمعرف المستخدم؛ ليس صلاحية وصول.
- داخل مساحة المصدر، تظهر متطلبات التشغيل عند وجود متطلبات أو تحذيرات مكتشفة، والبناء والاختبار عند وجود مهام أو سكربتات، ومخطط العمل عند وجود JSON معروف من n8n أو Node-RED. تبقى تشخيصات المخططات المعروفة غير الصالحة متاحة، بما فيها امتداد `.JSON`.
- زر «إظهار كل الأدوات» يتيح الاستكشاف اليدوي. أمثلة اللغات داخل قائمة قابلة للفتح. خصائص JSON الخام وتخصيص الجوال وتحرير تعريفات المهام داخل تفاصيل متقدمة.
- قطعة المصدر تفتح ملفات المشروع من خصائصها بدل عرض محرر HTML الخاص بالعنصر المؤقت. النسخ المرتبطة تُحيل إلى قطعة المصدر.
- مسودة تعريفات المهام محفوظة في حالة مساحة البرمجة خارج التبويبات؛ لا تضيع عند التنقل بينها. تبويب المهام يبقى متاحًا أثناء وجود تعديل غير محفوظ، ويُحجب تصدير المصدر حتى حفظه أو تجاهله. إغلاق المساحة أو تغيير المصدر يطلب تأكيدًا عند وجود تعديل ملف أو مهام؛ مغادرة الصفحة تستدعي تحذير المتصفح.
- تغيير طريقة عرض أدوات الخصائص لا يعيد إنشاء محررات JSON، ولا يزيل مسودتها.

التكيف يعتمد على محتوى المشروع واختيار المستخدم، دون تصنيف مهارته أو تعقبه. لا يفتح النظام نوافذ أو يشغّل كودًا أو يبدأ عملية مدفوعة تلقائيًا. صلاحيات المشروع والحماية على الخادم باقية؛ إخفاء أداة ليس عزلًا أمنيًا.

التحقق: ثلاث حالات اختبار لسياق المشروع والاختيار اليدوي واكتشاف المخططات، واختبارات المصدر القائمة، وفحص HTML المبني للوضع الافتراضي. لم تُجر تجربة تفاعل متصفح جديدة؛ إصلاح حفظ مسودة المهام ومحررات الخصائص راجعناه في الكود، وليس باختبار متصفح.
