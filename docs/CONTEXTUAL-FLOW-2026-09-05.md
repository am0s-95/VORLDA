# تحسين مسار الإضافة والتعديل والتسليم

طلب المالك: تقليل التعقيد مع الاحتفاظ بالتحكم وجودة المخرجات.

## السلوك المنفذ

- تعرض قائمة الإضافة وجهة العنصر قبل إضافته. الاختيار التلقائي يستخدم الحاوية المحددة، أو أقرب صفحة/قسم/مجموعة/نموذج يحوي العنصر المحدد. في غياب ذلك يستخدم النطاق المفتوح ثم الورشة. يستطيع المستخدم اختيار حاوية أخرى أو خارج الصفحات صراحةً. الصفحات الجديدة تبقى مستقلة. ينطبق تحديد الوجهة على إدراج الوسائط الأصلية أيضًا.
- إصلاح مسار صفحة ثم نص: كان التحديد لا يغيّر نطاق الإضافة، فيوضع النص خارج الصفحة ويغيب عن تصديرها. يستخدم المسار الجديد الحاوية المحددة؛ لم تنقل قطع المشاريع الموجودة تلقائيًا.
- يبدأ محرر النص والصورة والوسائط بالمحتوى، وتبدأ الصفحات والأقسام والمجموعات بالتصميم. فتح مشكلة رابط يذهب إلى تفاعل القطعة المصدر مباشرةً.
- يبقى المقاس والمظهر ظاهرين؛ الموقع والدوران والتخطيط، والقص والقناع وتعديلات الصورة، وتفاصيل الحدث والشروط والتنقل ضمن أقسام قابلة للفتح. الوضع المتقدم يفتح الأقسام تلقائيًا. لم تتغير قيم الضبط أو حدودها أو صيغ التصدير أو جودة الناتج.
- تبويبات الخصائص تحتفظ بحقول JSON غير المعتمدة أثناء التنقل داخل القطعة نفسها. محرر كل قطعة له مفتاح مستقل حتى لا يطبّق حقلًا من قطعة سابقة على الحالية؛ تبديل القطعة ينشئ محررًا مستقلًا.
- التسليم يبدأ بهدفين: رابط خاص أو تنزيل المشروع. يوضح المسودة/الإصدار المعتمد، ويعرض فحوص النسخة المطابقة. الملاحظات غير المانعة ضمن قسم اختياري، والأخطاء المانعة لها مسار لفتح القطعة مباشرةً. المعاينة والتصدير ومراجعة القطعة تتضمن العودة للتسليم، مع حفظ اختيار الهدف.
- تظل الموافقة على التكلفة عند وجود عرض مدفوع منفصلة. النشر لا يتم تلقائيًا بعد اعتماد المسودة. التصدير يحتفظ بصِيغه ومصادره وإعداداته السابقة. لم تتغير حماية الدخول أو الجمهور أو الفوترة أو واجهات الخادم.
- تميّز حالة الحفظ الآن بين انتظار الحفظ، والحفظ الجاري، والخطأ، والمسودة المحفوظة، والإصدار المعتمد. الإصدار صفر لا يُعرض كنسخة معتمدة.

## التحقق

29 اختبارًا مستهدفًا نجحت، مع البناء وفحص TypeScript. المراجعة المستقلة قارنت أدوات الخصائص قبل التغيير وبعده وتحققت من مسار التصدير فعليًا. لم يتم التحقق بالتفاعل داخل متصفح بسبب تعذّر اتصاله.

## تجربة الهاتف المطلوبة

1. أضف صفحة ثم نصًا؛ افتح الإضافة مجددًا وتأكد من ظهور اسم الصفحة كوجهة.
2. افتح نصًا وصورة، وتأكد من بدء الخصائص بالمحتوى وإمكانية فتح الضبط التفصيلي.
3. أنشئ رابطًا بلا وجهة، وافتح التسليم ثم راجع القطعة؛ يجب فتح تبويب التفاعل، ثم العودة للتسليم.
4. عاين المسودة، وارجع للتسليم، واعتمد التغييرات؛ النشر يظل إجراءً مستقلًا.
5. اختر تنزيل المشروع ثم ارجع من خيارات التصدير؛ يجب الاحتفاظ بهدف التنزيل.
